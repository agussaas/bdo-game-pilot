  • Reset dicentang; Agris sebelum reset 60,000 (reset di tengah shift): yang masuk penuh 20,000, Agris yang digunakan: 87,500

  • October 2026, Input AVG 75.76: KPI 88.43 (3 × 75.76 − (59.61 + 79.24)), Tier Tier 0
  • Sebaliknya, Input KPI 88.43: AVG Oktober 75.76

Calculator

  • Hitung di kolom Input, hasilnya akan muncul otomatis di Result
  • Operasi perhitungan:
    • + tambah
    • - kurang
    • * kali (boleh juga x atau ×)
    • / bagi (boleh juga ÷)
    • ^ pangkat (boleh juga **), contoh 2^3 = 8
    • % persen, contoh 15% = 0.15
    • ( ) kurung
  • Urutan perhitungan: kurung dulu, lalu % dan ^, lalu * dan /, terakhir + dan -
  • Satuan ditulis langsung setelah angka tanpa spasi: k (ribu), m (juta), b (miliar), t (triliun), contoh 500k, 1.5m, 2b
  • Angka memakai titik dianggap sebagai desimal (12.5). Koma dengan tepat 3 angka di belakangnya dianggap pemisah ribuan, jadi 1,000,000 sama dengan 1000000. Notasi ilmiah juga bisa, misal 1e3 = 1000
  • Untuk JavaScript, ditulis dengan kurung (awalan Math. juga bisa): abs, sqrt, cbrt, pow, exp, expm1, log, log2, log10, log1p, sin, cos, tan, asin, acos, atan, atan2, sinh, cosh, tanh, asinh, acosh, atanh, floor, ceil, round, trunc, sign, min, max, hypot, fround, clz32, imul, random. Sudut untuk sin, cos, tan memakai radian
  • Konstanta: pi, e, ln2, ln10, log2e, log10e, sqrt2, sqrt1_2
  • Pemisah argumen: ; atau koma, misal max(5; 10). Hati-hati, max(1,500) tanpa spasi dibaca 1,500 (seribu lima ratus), jadi pakai ; atau beri spasi setelah koma
  • % hanya membagi angka di depannya dengan 100. Untuk menambah persen tulis lengkap: 200 + 200 * 10% = 220, bukan 200 + 10% yang hasilnya 200.1
  • Hasil di atas 1,000 ditampilkan: K ribu, M juta, B miliar, T triliun (dalam kurung)
  • Jika salah tulis, Result otomatis menampilkan error message, misalnya kurung kurang, karakter tidak dikenal, atau tidak bisa dibagi nol
  • Contoh: 1.5b * 65% hasilnya 975,000,000 (975 M), (5m + 250k) * 2 hasilnya 10,500,000 (10.5 M), 100 / 8 hasilnya 12.5
  • Contoh fungsi: sqrt(144) hasilnya 12, max(5m; 250k * 30) hasilnya 7,500,000 (7.5 M), round(100 / 3) hasilnya 33, hypot(3; 4) hasilnya 5
